## 搜索深度

IGA-180 平均评估 8.875 个完成候选，118/120 例未完成 20 个个体的初始种群评估，只有 2 例进入下一代。因此它主要衡量短预算采样与最优解保留，尚不能代表充分进行交叉/变异后的 IGA。

IGA-1800 续跑阶段平均新增 82.817 个完成候选，累计两段平均 91.692 个；续跑完成 3–8 代。不能把 82.817 错报成 1800 秒累计候选数。第一段实际搜索时长 180.0008–180.2157 秒，第二段 1620.0006–1620.3348 秒。

续跑最后一条代际记录仍刷新最优值的案例为 25/120，说明部分案例在预算末端仍有改进；日志不足以断言已收敛，也不足以推算再增加预算的收益。搜索深度依赖同机并发和硬件，不应直接与不同并发下的 IGA 数值混比。

## 标签审计与解释范围

对齐的 60 例全部为相同内容指纹，但其中 32 例的旧评测分布标签来自旧 manifest 覆盖。历史计数是 29/29/2，真实数据计数是 30/27/3。按真实标签，IGA-180 / IGA-1800 的对齐60综合分为 9383.42 / 9038.50，P5 为 9196.78；按历史标签对应 9368.48 / 9024.16 / 9184.71。完整 validation120 使用真实标签 60/54/6。

真实标签的 OOD-stress 均值高于 IID，符合该批案例更难的观测；历史分组中出现的 IID 高于 stress 不能作为 OOD 鲁棒性证据。这里保留历史 Best checkpoint，不按修正后的标签重新挑选模型。

本轮仅比较 Stage1、heuristic 资源后端与匹配的 validation 案例。Stage3 的全联合控制/H3F4 结果与历史独立 test60 都不并入此表。

|---|---|
| Simpson reversal | 两种标签口径均保留；IGA/P5 总体优劣方向未反转；真实标签下三分布也同方向。 |
| Ecological inference | 按案例配对；跨 seed 平均不视作可部署集成策略。 |
| Selection / Berkson | validation60 用于选 Best，报告受限于该验证集；不能视作独立泛化检验。 |
| Collider adjustment | 无事后协变量调整；不适用。 |
| Base-rate neglect | 非分类/筛查任务；案例分布与权重均明确。 |
| Regression to mean | 固定全部案例；无按极端结果删选；最优解保留导致单调性已披露。 |
| Survivorship | 两档各120/120成功，未剔除失败案例。 |
| Look-elsewhere | 全部5个学习方法均报告；附加区间为探索性，未作多重显著性结论。 |

| Causal overclaim | 不把算法、算力、初始化差异归因于某一网络结构。 |
| Reverse causality | 固定配置的求解结果比较，不做观察性方向因果推断。 |
