The execution recipe uses global batch 240 and PPO microbatch 80. Each full

## CPU environment scheduling

There are 240 independent environment instances and up to 240 observations in
each GPU inference batch. They are hosted by 64 CPU worker processes, each with
3 or 4 environment instances. Logical slot `i` routes to worker `i % 64`; each
slot owns its environment, step counter, and Python/NumPy/Torch CPU RNG state.
Only reset configuration and actions cross the CPU worker boundary. Workers
cannot see CUDA and do not load models. This avoids 240 Python/Torch interpreter
copies while retaining all 240 environment states. At epoch-ending partial
groups the number of active slots follows the remaining visit count.

CPU worker shutdown broadcasts the close command to every worker before joining
processes. The model and Adam state stay in the trainer for PPO updates.
